# Yatmo Neighbourhood Map for Odoo

Map, points of interest, travel times and an indexable neighbourhood text on the property pages of
an Odoo website (Odoo 17.0 to 20.0, one package per series). A Yatmo licence key is required: https://yatmo.com.

- Two building blocks in the website builder: **Yatmo Map** (Content group) and **Yatmo Text** (Text group).
- Two QWeb templates for pages generated from your own records: `yatmo_map.map` and `yatmo_map.text`.
- Site defaults in Website > Configuration > Settings > Yatmo neighbourhood map.

Documentation: https://documentation.yatmo.com/plugins/odoo
