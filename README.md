# Yatmo Neighbourhood Map for Odoo

Map, points of interest, travel times and an indexable neighbourhood text on the property pages of
an Odoo website. A Yatmo licence key is required: https://yatmo.com.

One branch per Odoo series, each holding the `yatmo_map` module at its root:

| Branch | Odoo |
|---|---|
| `17.0` | Odoo 17.0 |
| `18.0` | Odoo 18.0 |
| `19.0` | Odoo 19.0 |
| `20.0` | Odoo 20.0 |

Documentation: https://documentation.yatmo.com/plugins/odoo
